# Housing Market Analysis using Tableau

##  Project Title
**Visualizing Housing Market Trends and Analysis of Sale Prices and Features Using Tableau**

##  Project Overview
This project focuses on analyzing housing market trends using Tableau. The dashboard provides meaningful insights into house sale prices and various property features through interactive visualizations. The analysis helps users understand how different housing characteristics influence property prices and supports better decision-making.

##  Objectives
- Analyze housing market trends.
- Understand the factors affecting house sale prices.
- Compare house features such as bedrooms, bathrooms, floors, and house age.
- Build interactive dashboards and stories for easy data exploration.

##  Tools & Technologies
- Tableau Public
- Microsoft Excel
- GitHub

##  Dashboard Features
- Average Sale Price Analysis
- House Age Distribution
- Number of Bedrooms Analysis
- Number of Bathrooms Analysis
- Number of Floors Analysis
- Renovation Status Analysis
- Interactive Dashboard
- Story Presentation

- Housing Project.twb

##  Key Insights
- Sale prices vary based on house features.
- Renovated houses generally have different market trends compared to non-renovated houses.
- Property characteristics such as bedrooms, bathrooms, floors, and house age influence selling prices.
- Interactive dashboards make it easier to identify trends and compare housing data.

##  Future Enhancements

- Publish dashboards with live data updates.
